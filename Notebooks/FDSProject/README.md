# Project Description

This project predicts residential appliance energy consumption using Machine Learning and Deep Learning models in Python (Google Colab).
The dataset includes indoor and outdoor environmental conditions, weather data, and time-based features.

## The project focuses on:

Exploring and understanding the dataset (EDA)
Data cleaning and preprocessing
Feature engineering (time features and lag variables)
Training and comparing models:
Linear Regression
Random Forest
XGBoost
Artificial Neural Network (ANN)
Long Short-Term Memory (LSTM)
Evaluating models using RMSE, MAE, MAPE, and R²
